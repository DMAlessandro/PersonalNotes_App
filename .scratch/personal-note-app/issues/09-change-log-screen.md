## Question

How do you browse and use the Change log (every Cross-out and Delete, kept per week, with full content)?

- Per Project, global, or both? Where is it opened from?
- What does an entry show, and how is it grouped (by week, by Project)?
- What does "Restore" do for a Deleted Item whose parent or Project no longer exists? And for a Cross-out entry?
- Can entries ever be removed from the log, or is it permanent?

## Answer

Resolved with the user, 2026-10-01.

- **Two ways in** (user): the **Log** button inside a Project shows that Project's entries. A global **Change log** in the main menu shows everything, including Deleted Projects.
- **Listed by week, newest first** (user): "This week", "Last week", "Week 38"…, matching the weekly files. Each entry shows what happened (Crossed out / Deleted / Restored), the Item text, its Project, the date, the device, and how many Items were under it.
- **Restore a Delete = restore the chain** (user). If the parent Task or the Project is also gone, they come back too, so the Item lands where it was. A **Cross-out entry** offers "Un-cross" while the Item is still crossed out. *(Agent default.)*
- **Permanent** (user): entries are never removed. Restoring adds a "Restored" entry; it doesn't erase the old one.
