# Laptop shortcuts for adding and editing

Type: grilling
Status: resolved
Blocked by: 01, 06, 07

## Question

What mouse/keyboard shortcuts does the laptop version need for adding Items quickly?

## Answer

Resolved with the user, 2026-10-05 (request raised by the user).

Applies to **both the List view (Cards) and the Map view** on laptop.

- **Double-click on text** of an Item → edit it in place (as already decided for the Map).
- **Double-click on empty space** (outside any Item) → a new top-level **Task** in the Project, already in edit mode.
  - In the List view, the Project is the one that's open.
  - In the Map view, double-clicking empty space beside a Project's branch adds the Task to that Project. On the far background (e.g. in All Projects), it goes to the Project last used.
- **Selection:** a single click on a box/card **selects** it (highlight outline). Clicking empty space or pressing **Esc** clears the selection.
- **Ctrl+Enter:**
  - while **editing** an Item, or with an Item **selected** → save, then create a **sibling of the same type** (Task → Task, Note → Note) **directly below it** at the same level, already in edit mode;
  - with **nothing selected and nothing being edited** → a new top-level **Task** in the current Project (Map: the Project last used).
- **While editing:** **Enter** = save and stop editing; **Shift+Enter** = line break inside the Item; **Ctrl+Enter** = save and add a sibling (above); **Esc** = cancel (a new, still-empty Item is discarded).
- A sibling "directly below" sits right after the current Item in the manual order. Deadline ordering still applies if it gets a due date.
